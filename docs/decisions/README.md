# Decisions

One file per decision: `NNNN-short-title.md`. Write one whenever you choose
between real alternatives. The *why* is what you'll have forgotten in six months.

```markdown
# ADR-NNNN: Title

- **Date:** YYYY-MM-DD
- **Status:** Proposed | Accepted | Superseded by ADR-XXXX

## Context
What problem, what forces, what you knew at the time.

## Decision
What you chose.

## Alternatives considered
What else, and why not.

## Consequences
What gets easier, what gets harder, what you'll need to watch.
```
